# Seth Badri Prasad D.A.V. Centenary Public School Website

A static, multi-page website for Seth Badri Prasad D.A.V. Centenary Public School in Fatehabad, Haryana. It presents school information, admission guidance, faculty details, campus facilities, and a photo gallery.

## Features

- School overview, messages, and mission and vision
- Admission policies and faculty profiles
- Infrastructure information, including the library, computer lab, medical room, and science labs
- Campus photo gallery
- Shared navigation, contact information, and an embedded Google Maps location

## Technology

- HTML for page content and navigation
- CSS embedded in each HTML page
- JavaScript embedded in pages that rotate banner images
- Local image files stored in the repository root

This project has no build step or package dependencies.

## Getting started

1. Clone or download the repository.
2. Open `index.html` in a web browser.

The site is static and can be previewed directly from the filesystem. An internet connection is needed for the embedded Google Maps content.
