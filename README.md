# 🏫 School Website

A responsive and user-friendly **School Website** designed to provide students, parents, teachers, and visitors with easy access to essential school information. The website serves as a digital platform that showcases the institution's vision, infrastructure, facilities, admission details, and campus activities through an attractive and organized interface.

Built using front-end web technologies, the project demonstrates modern web design principles, responsive layouts, and intuitive navigation. It is an excellent project for beginners learning HTML and CSS while creating a real-world educational website.

---

## 📖 Features

- 🏠 Interactive Home Page
- 🏫 About the School
- 📝 Admission Information
- 👨‍🏫 Faculty Details
- 🏢 Infrastructure Overview
- 📚 Library Information
- 💻 Computer Laboratory
- 🩺 First Aid Facility
- 🖼️ Photo Gallery
